# 🛡️ Anti-Scam Awareness & Reporting Portal

**Privacy-first educational web demo** to help users understand online scams, safe permissions, and responsible browsing. This project is for **portfolio and educational purposes only** — no personal data is collected or stored.

---

## 🚀 Live Demo

You can try the demo online here:  
live demo - (https://anti-scam-awareness-portal.vercel.app) 🌐  

Or try locally by opening the `index.html` file in your browser.  
Optional features like camera preview and location are **consent-based**.

---

## 🧰 Features

- **Scam Awareness Section**  
  Explains common scam tactics like fake alerts, pressure tactics, and suspicious permission requests.

- **Safe Permission Demo**  
  - Optional camera preview (educational only)  
  - Location sharing demo (consent required)  
  - Clear guidance on safe website practices

- **Official Reporting Section**  
  Provides a link to the **National Cyber Crime Reporting Portal (Govt. of India)** for reporting suspicious activity.

- **Privacy-First Approach**  
  No data is collected, stored, or transmitted.

---

## 💻 Tech Stack

- **HTML5 & CSS3** – Semantic markup & styling  
- **Tailwind CSS** – Modern utility-first CSS framework  
- **Vanilla JavaScript** – DOM manipulation & permission handling  
- Fully client-side, no backend required
